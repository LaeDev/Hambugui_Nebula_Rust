# GUI UX fixes — decisions (design lead) for Task 6c

Source: heuristic audit (41 findings, 7 accessibility items). Decisions below are final. Items marked **skip** are accepted ceilings and documented in DESIGN.md §11.

## Must fix

1. **Verdict gating (F1, F2).** The stamp and the 업로드 button are gated on a **strict** validation pass. After `generate`, run `validate(&distribution, strict = true)` for the gate and `strict = false` for the displayed findings. Stamp = strict report has zero errors. `PublishData.can-publish` = target selected && file exists && the last strict validation of *that file name* passed (on startup and when the name changes, validate the file on disk silently with strict=true to set the gate). When strict fails but non-strict passes, the summary line ends with `· 런처 배포 불가` and the helper under 업로드 says why (`http:// URL 또는 SHA-256 누락이 있어 런처가 거부합니다. 오류 목록을 확인하세요`). The file is still written (users may inspect it).
2. **Progress visibility (F3, F4).** Busy eyebrow shows elapsed time updated by the existing 100 ms timer: `작업 중: 배포본 생성 · 1분 23초`. Log band auto-scrolls to the newest row when rows are appended (set the ListView `viewport-y` to the end unless the user scrolled up in the last 5 s — simplest acceptable: always scroll to end on append). Log rows carry a level and paint `danger` for error, `warning` for warn, `text` otherwise (F20).
3. **Job-kind failures and retry (F7, F8).** `SheetData.error-kind: string` (`generate` | `validate` | `init-root` | `publish`) and `error-text`; the sheet prefixes `생성 실패:` / `검증 실패:` / `초기화 실패:` / `업로드 실패:` accordingly and 다시 시도 re-runs the same job kind with the *current* field values. Below the retry, when the message mentions the cache, show the hint `Forge 설치 캐시 무효화를 켜고 다시 시도하세요` — no hidden magic.
4. **Navigation while busy (F6).** Back button and Esc work while busy (the sheet shows the busy state). Only actions that start jobs stay disabled. Cancellation itself is **skip** (documented ceiling: installer has a 10-minute timeout).
5. **Settings (F13, F14, F15).** Enter in any settings field triggers 저장 (`Field.accepted` → `save-settings`). Theme and reduced-motion apply and persist immediately when changed, independent of root/base-URL validity. Base URL and root validate on `Field.edited` (debounced by the timer tick, 300 ms) and errors clear as soon as the value becomes valid. Move 저장 to a fixed row directly under the group title area? No: keep it at the end but add a second 저장 button at the top-right of the settings header (same callback) so it is visible without scrolling.
6. **Per-screen busy (F19).** `NewServerData.busy` is true only during create-server; `lookup-busy` only during lookups; `ImportData.busy` only during import; `SettingsData.busy` only during save; the Google connect button gets its own `gdrive-busy` and a status line under it for success/failure (F21). `SheetData.busy` remains the global job lock.
7. **After a successful build (F16).** Scroll the sheet so the result band (summary + stamp) is at the top of the viewport; the 배포 band then sits directly below it.
8. **Refresh (F17).** Add a ghost button `새로 고침` in the servers band header (left of 모드팩 가져오기) → `SheetActions.refresh`.
9. **Disabled 업로드 explains itself (F18).** Helper line under the button: `대상을 선택하세요` / `먼저 배포본을 생성하세요` / the strict-failure text from item 1.
10. **Log time (F27, A-tz).** Replace UTC `HH:MM:SS` with elapsed time since launch `+MM:SS` (locale-free, honest). Remove the UTC notice line. The stamp shows three lines: `검증 통과`, `distribution.json` (the file name), `SHA-256 a91f3c02` — no clock. `stamp-time` property is dropped; `stamp-file` added. Stamp clears when the file-name field changes (F28).
11. **Copy and labels (F22, F25, F26, F30, F31, F32, F37, F40, F41).** Import copy is generic (`모드팩 zip 또는 mrpack을 modpacks 폴더에 넣으면 여기에 표시됩니다`; accessible labels say 모드팩). Findings show `Test-1.12.2 · modules[7].artifact.url` (server id instead of `servers[i]`). Summary: `파일 484 · SHA-256 484 · 오류 0 · 경고 2`. Publish result: `WebDAV로 312개 업로드 · 172개 변경 없음` then a labelled line `배포 URL` + selectable URL. Init banner: `이 루트에는 meta/distrometa.json이 없습니다. 루트 초기화는 기본 메타 파일과 폴더를 추가하며 기존 파일은 그대로 둡니다.` Readiness missing rows show `미설정` in the value column. Replace `docs/launcher` references in UI text with `README의 NeoForge 항목을 참고하세요`. Fix `{dir_name} 로` → `{dir_name}(으)로` using a tiny final-consonant check (Hangul jongseong) — or restructure: `모드팩을 가져왔습니다: {dir_name}`. Generic job failures (disk/network/zip) go to `error-text` on the current screen, not under 서버 ID; only id/version validation errors attach to fields.
12. **Selectable URLs (F34) and placeholders (F35).** Read-only URL inputs get a 1 px `line` border and the helper `드래그해서 선택한 뒤 Ctrl+C로 복사`. `Field` gains `placeholder` (muted text shown when empty): root `D:\NebulaRoot`, base URL `https://cdn.example.com/`, Java `C:\Program Files\...\java.exe`, server id `my-server`, MC version `1.20.1`, loader version `latest`.
13. **Accent dose (F36).** 확인됨 chips use `text` (not primary). Keep primary on the primary button, checked toggles, and selected exclusive buttons (selection needs a strong cue).
14. **Lists (F23, F24).** Import list and findings list become `ListView`s with max heights (import 5 rows, findings 6 rows) and their own scroll.
15. **Accessibility (A1, A2, A3).** `Field` sets `accessible-description` to the error or helper text. `ServerRow` is not a focus stop (remove its FocusScope/role); 폴더 열기 stays the one stop. A loading primary keeps its focus scope enabled (focus is not dropped when `busy` flips).
16. **English core messages that reach the UI (F11, F12).** Translate to Korean with cause + fix only the errors a GUI user is likely to hit: installer produced no manifest (name the directory and say `Forge 설치 캐시 무효화를 켜고 다시 시도하거나, 설치기 창이 열리면 다음 폴더를 선택하세요: …`), Java not set, root/base URL not set, "Server already exists", modpack not found, unsupported loader (quilt / legacy NeoForge 1.20.1). Core *log* lines stay English (they mirror upstream and are grep-able against upstream issues) — accepted ceiling.
17. **Import banner (F10).** Move the shouty manual-download banner out of `import_modpack` into the CLI (`cli.rs`) so the GUI shows only the Korean box; `import_modpack` logs one line: `N files require manual download`.

## Skip (documented ceilings)

- Job cancellation (F5): installer timeout 10 min; other jobs are seconds to a minute.
- Server path in the row (F29): 폴더 열기 covers it.
- Log clear confirmation (F33): the ring buffer is 400 rows and clearing is a deliberate click.
- Live-region announcements (A4): Slint 1.17 has no live-region API. **Superseded
  2026-09-11**: `accessible-live-region` exists in Slint 1.17.1 and is used by
  `ProgressRow` (DESIGN-v2 §8.7).
- Korean core log lines (F9).
